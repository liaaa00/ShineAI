# 可用性修正（2026-10-18）

本轮修正来自实际界面检查，范围为内置技能、模型接入说明、skills.sh 社区市场和任务工作目录。

## 修改内容

- 内置技能：纠正翻译、解释代码、编写测试等技能的名称、描述、参数标签和错配提示词。保持原有 ID、命令、服务商兼容性和编排结构；并行分析的两个步骤改为对应的分析角度。这些是本地维护的默认提示词，不是恢复作者未公开的原文。
- 旧数据升级：仅替换与旧默认值完全一致的字段。用户改过的提示词、参数、名称以及禁用状态、自建技能会保留。任一字段保存校验失败时，由原有种子事务回滚；不会迁移官方账号数据。
- 模型服务：入口说明改为接入自己的服务商、测试连接、在会话中选用模型；标题等辅助模型按需分配。创建表单直接显示接入方式，说明 OpenAI API、Anthropic Messages 和 Responses 的区别；具体选择以中转文档为准。本轮没有新增协议或改变服务商额度。
- 社区市场：区分网络、DNS、超时、HTTP 和页面格式错误，提供重试。保存当前进程中最近一次成功列表，缓存有效期 30 分钟；刷新失败时显示旧列表和缓存时间。重启后的缓存不持久化。仍支持公开 Skill/MCP 市场；不执行市场网页脚本。
- 工作目录：输入框下方显示实际任务目录，命名工作区使用实际主仓库路径。自动生成目录会说明“发送时按任务名创建子目录”；临时目录会说明发送时另建子目录。长路径可悬停查看，目录菜单解释执行位置和访问权限的区别。
- 恢复脚本：外观补丁只添加自己的接口命名空间，避免重新生成源码时删除文件侧栏预览接口。

## 验证范围

新增单元检查覆盖旧默认值迁移、自定义内容保留、重复启动、市场页面解析、缓存、强制重试、错误分类及恢复补丁兼容。

`npm run smoke:usability` 使用隔离的真实 Electron 窗口和 SQLite：写入旧技能记录后重启，检查修正和用户内容保留；操作模型创建表单的三种接入方式；检查主仓库目录和重启保存；用本机 HTTP 服务模拟市场首次失败、重试成功、刷新失败保留缓存和再次恢复。不会发送付费模型请求，也不替代实际中转服务的兼容性验证。

运行时修改须通过 `npm run check`。工作台启动布局与文件点击另有专项检查；安装版更新后须用隔离配置复测。测试产物保存在本地 `artifacts/usability-fix` 和 `artifacts/usability-audit-2026-10-18`，不提交个人数据库、密钥或聊天内容。

本轮更新已安装程序时，仅替换生成的应用代码；独立备份数据库和旧应用文件。已有安装包不会自动更新，本记录不表示重新生成了安装器。
