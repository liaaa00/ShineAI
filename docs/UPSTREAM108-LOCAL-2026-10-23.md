# 官方 1.0.8 本地功能迁移

本次保留 ShineAI 原有工程与修复，选择性迁入官方 1.0.8 的本地功能。应用基线仍是 1.0.6，不代表完整覆盖为官方 1.0.8，也没有恢复官方云端服务。

## 使用入口

- **设置 → 工作工具 → 工作日报**：按日期查看本机会话、使用已配置的模型整理、补录或编辑事项，导出 HTML、PDF 或 PNG。日报模型可单独指定；留空跟随摘要模型设置。定时生成默认关闭；启用后应用需要保持运行。定时导出保存在系统“文档”目录的 `ShineAI/Daily reports`，提醒使用应用内提示。超长日报请导出 PDF/HTML，PNG 不会静默裁掉后半部分。
- **设置 → 工作工具 → 网页大模型**：默认关闭。确认内容将发给所选第三方网站后，可以添加预设或自定义网站、登录、测试以及拾取页面元素。通过 `shineai-web-llm` MCP 提供 `web_llm_list_sites` 和 `web_llm_ask`。网站登录、验证码、额度及页面改版仍由对应网站决定。
- **设置 → 常规 → 内置浏览器 → 导入浏览器登录状态**：支持 Cookie JSON 和 Netscape cookies.txt。导入前显示目标和域名，默认选择取消；普通浏览器和网页模型专用浏览器分别导入，网页模型的登录状态固定隔离，会话隔离的其他浏览器也不自动共享。
- **内置浏览器工具栏 → 交给 AI**，或浏览器设置中的对应按钮：把网页标题、地址、正文追加到当前会话草稿，由用户检查后发送。不会直接发模型，也不会替换已有草稿。
- **工作区设置 → 工作区显示顺序**：上下移动后立即保存，侧边栏同步刷新，重启后保留。
- 已被清理的 worktree 中的文件链接：原路径不存在时，尝试回到所属仓库的同名文件。保留既有的文件访问范围、真实路径校验和只读确认。

## 记忆机制的后续更新

首轮迁移按当时的要求保留了记忆机制。用户随后明确要求跟随官方新版，已另行迁入记忆核心更新：通用规则分类与自动置顶、3500 字／18 条注入预算、话题排序及冷层已确认规则的注入。已有记忆内容和设置保留，首次读取旧目录前自动备份。详见 [记忆更新说明](MEMORY108-2026-10-23.md)。

日报另建表保存，不写入记忆，不会自动生成或覆盖会话交接记录。分组简报、技能推荐和分组决策提案流程未随本次记忆核心更新迁入。

公开 Skill/MCP 市场继续保留。官方账号、会员、遥测、云协作、手机中继等保持移除状态。网页模型站点预设使用本地内置清单，刷新不请求官方云端。

## 工程实现

`scripts/import-official108.mjs` 固定校验已分析的官方发布包 SHA-256，再抽取日报、网页模型的依赖闭包和 UI。输出在 `src/main/upstream108` 与 `src/renderer/assets/upstream108*`。官方恢复目录和 `archive/official-1.0.6` 不变；日常构建直接使用已生成的模块，不依赖官方安装目录或解码缓存。

可维护的桥接代码在 `src/main/extensions/upstream108.cjs`、`browser-cookies.cjs`、`moved-path.cjs`、`web-llm-state.cjs`、`web-llm-mcp.cjs`。模型调用复用 ShineAI 原有连接模块，UI 复用现有 React、主题和会话状态；沙箱、上下文隔离和 IPC 来源校验继续生效。

数据库首次添加日报表前使用 SQLite `VACUUM INTO` 备份至当前资料目录的 `backups`，仅添加本次所需表和字段，不推进旧版本的迁移编号。工作区排序独立存表。网页模型设置与 MCP 管理页共用一个启用状态，关闭后工具会拒绝执行；新增内置 MCP 已加入启动保留名单。

## 验证方式与边界

运行 `npm run check`，以及 `npm run smoke:upstream108`。后者启动完整 Electron 应用，使用独立资料目录和本地模型、网页测试服务，覆盖聊天回复、日报模型整理、手动事项、导出、真实浏览器标定和提问取回、MCP 标准输入输出协议、Cookie 隔离、网页追加草稿与重启持久化。

测试不会使用用户真实密钥、发送真实网站消息或修改用户记忆。真实第三方站点登录和持续兼容性仍需要使用对应账号与网络环境验证。自动定时服务的真实墙钟触发和 macOS 运行效果不在本机这轮完整实测范围内。

首轮测试记录位于 `artifacts/upstream108-smoke`。其中“101 个记忆方法未变”的记录只描述首轮迁移，不能作为后续记忆更新的结果。后续记忆测试记录位于 `artifacts/memory108` 和 `artifacts/official108-review/memory-upgrade`。
