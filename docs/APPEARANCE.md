# 背景与玻璃效果

入口：设置 → 常规 → 外观 → 背景与玻璃效果。

选择图片或视频即可启用。图片支持 PNG/JPG/WebP/GIF，最大 20 MB；视频支持 MP4/WebM，最大 150 MB。视频还需要 Electron 支持其具体编码，H.264 MP4 和 VP8 WebM 已用生成媒体测试。背景最多 4000 万像素。

媒体复制到开发版用户数据的 `appearance/media`；设置存入 `appearance/settings.json`，无需保持原文件位置。工程版使用独立 `.data`，安装版使用 `%APPDATA%\ShineAI`。

| 控件 | 效果 |
| --- | --- |
| 背景强度 | 图片/视频显示得更浓或更淡 |
| 背景遮罩 | 浅色主题提白、暗色主题压暗 |
| 面板透明度 | 数值越高，页面、卡片、抽屉、菜单、弹窗和输入框越通透；文字不会一起变淡 |
| 背景模糊 | 0–24 px，动态背景建议使用较低值 |
| 浮层模糊 | 0–24 px，控制面板、菜单及输入区后方的模糊；0 完全关闭 |
| 显示方式 | 铺满窗口可能裁切；完整显示保留整张图 |
| 水平/垂直位置 | 调整画面焦点 |
| 动态播放 | 静音循环；关闭时显示静态画面 |

原画视频、清晰壁纸、柔和玻璃、专注阅读是参数预设，选中后仍能调整。明暗主题分别保存效果参数；换主题不必重导入背景。预览是静态画面，避免设置页额外播放一份视频。

“原画视频”将当前明暗主题的强度、面板透明度设为 100%，遮罩、背景模糊、浮层模糊设为 0，并启用动态播放、完整显示与居中。不会转码或锐化原视频；窗口与视频比例不同时有留边。铺满模式可能裁切和放大。全透明界面随画面变化，文字可能变得难读，可自行降低面板透明度。浅色/暗色需分别选预设。

建议先选柔和玻璃。如果壁纸太花或文字难看清，提高背景遮罩、降低面板透明度；如果壁纸太淡，提高背景强度。视频和高分辨率动图建议先关闭模糊。

隐藏窗口时暂停动态背景；系统开启减少动态效果时采用静态画面。视频在原解码分辨率直接暂停，GIF/WebP 切换到静态预览。视频、GIF 和动态 WebP 均可恢复播放。卡片、抽屉、菜单、设置弹窗、输入框和代码块的底色统一跟随面板透明度。浮层覆盖的下层界面会被局部裁去，露出同一份全窗背景；文字遮挡不依赖模糊强度。终端及代码编辑器主体透出全窗壁纸，文字、图标和 ANSI 颜色保留。

恢复默认关闭背景并重置效果，保留选择的媒体；清除背景取消媒体选择。有效导入的历史媒体副本保留在独立数据目录；导入但无法解码的候选文件会丢弃。损坏文件、取消选择或解码失败不会替换现有背景。

新增实现位于 `src/main/extensions/appearance.cjs`、`src/renderer/assets/dev-appearance.js` 和 `dev-appearance.css`。preload 仅开放选择、读取、验证后的保存及丢弃候选媒体；不允许 renderer 任意读取路径。媒体协议按随机标识返回数据，支持视频 Range，保持沙箱、来源检查和 CSP 行为。

`scripts/patch-appearance.mjs` 为恢复后的前端加上稳定区域属性和外观面板，并由恢复转换脚本调用；不会修改只读官方快照。

测试命令：`npm run smoke:appearance`，报告 `artifacts/appearance-smoke/report.json`。安装版测试：`node scripts/appearance-smoke.mjs --executable="E:/AI/ShineAI/ShineAI.exe"`。测试使用隔离数据、生成的媒体，不读取用户密钥或发送模型请求；截图像素验证需 Python Pillow。

## 视频清晰度修复（全局外观版 7）
