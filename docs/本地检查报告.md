已定位并移除主进程中的四类阻塞：代理检测多余的同步 PowerShell 查询；启动系统环境的同步读取；后台环境检查的同步工具检测；内置浏览器启动和自检时同步执行 netstat/netsh。系统环境读取、工具检测及运行阶段端口检查改为异步子进程，代理直接读取继承环境及应用配置。Chromium 启动前选择调试端口的原检查保留，避免改变必须在 app.ready 之前配置的浏览器能力。

Claude 参数、Codex 测试、市场及本地流程重新验证。最终性能检查的完整环境检测持续 7.3 秒，109 次独立 IPC 的最大响应时间为 115 毫秒；测试窗口两次启动均无停顿记录。具体证据见 `artifacts/local-runtime-smoke-report.json`。这些结果验证了已定位的阻塞点，不能证明所有操作都永远没有停顿。
