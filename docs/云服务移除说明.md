# 官方云服务移除与可读代码整理

用户希望移除官方云依赖，同时保留本地开发与自备模型能力。本次把七个发布类的实现从运行源码中删除，换成可读的本地身份或兼容模块；原始代码只保留在不可修改的 archive 快照中。

## 移除和保留范围

| 已移除 | 保留 |
|---|---|
| 官方注册、登录、密码、令牌刷新、会员购买、余额和签到 | 固定的本地开发身份和本地能力配置 |
| 官方内置模型及官方模型商店入口 | Codex、Claude、Gemini、自备 API、本地兼容模型服务 |
| 官方群聊、组织协作、组织云盘 | 本地项目、Git、文件、知识库与本地会话历史 |
| 官方云会议及其 HTTP/WebSocket 网关 | 本地终端；录音和本地工具资源没有作为云会议一起删除 |
| 官方中继、远程设备入口 | 自备机器人、局域网及第三方集成代码保留，未逐项验收 |
| 官方在线分享、HTML 托管和社区发布操作 | 本地 HTML 预览、文件保存、技能和 MCP 的本地管理，以及公开市场浏览、下载和安装 |
| 遥测上传、官方更新客户端、官方反馈接口 | 本地统计与日志；通过工程代码更新应用 |

“云端”有两个不同来源：ShineAI 官方平台，以及用户自己的模型服务商。本次移除前者。使用 Codex、Claude 或其他远程 API 时，仍需要对应账号、额度和网络；用户可以自行配置本地模型服务，但本次没有安装或验收本地模型。

公开技能和 MCP 市场也保留。技能官方目录来自 GitHub 上的 ShineAI registry，MCP 官方市场来自 `registry.modelcontextprotocol.io`，另有 skills.sh 等来源；这些公共资源不依赖官方会员。此前误拦截的六个市场读取、刷新和安装接口已经恢复。社区发布自己的内容仍属于已移除的官方云业务，与下载公开技能不同。

## 可读模块

- `src/main/extensions/local-identity.cjs`：本地身份与执行能力。不会读取已保存的官方登录，不创建刷新定时器，不提供官方令牌。
- `src/main/extensions/removed-cloud-services.cjs`：对旧调用保留无网络的生命周期接口。不会监听登录回调和会议端口。
- `src/main/security/official-cloud-policy.cjs`：主进程阻止官方业务 IPC，过滤内置官方模型，并拦截指定官方域名的主进程与浏览器请求。独立模型服务商及 localhost 不在禁止名单中。
- `scripts/remove-official-cloud.mjs`：使用 JavaScript 语法树定位并替换发布类，移除相关界面和控件，未知结构会报错。

保留少量返回“已移除”的接口是为了让旧前端或插件收到明确结果，避免缺少接口直接导致整个工作台崩溃。它们不再执行原来的云端业务。部分未使用的发布代码、翻译和第三方库仍在包中；本次没有对所有模块做全量重写或自动删库。

## 混淆是什么意思

发布代码中有很多 `a02`、`a0f` 一类变量和合并后的函数。字符串解码只能恢复一部分文本，无法证明每个变量原来叫什么。代码能运行和能修改，但阅读成本更高。

解决方法是按实际功能逐步分析，把功能迁到带清晰命名、边界和测试的模块中。本次已对身份、云服务边界做了这样的整理；其余发布业务没有被宣称为已经全部恢复。格式化代码也不等于恢复作者原始 TypeScript、注释或项目结构。

## 验证

`npm run check` 新增真实 Electron 云服务移除检查：旧登录与发布接口不能执行，官方请求被阻止，localhost 的自备服务地址仍可访问，云端服务不监听端口，设置中不提供账号、会员和更新按钮。

`npm run e2e` 继续验证项目、文件、Git、终端、真实 Codex 回复、重启保存与继续会话。真实模型请求会消耗少量用户服务商额度。

移除前的完整备份和 Git 历史仍保留，官方安装目录没有修改。本次不删除已有的本地项目、对话或数据库记录。
