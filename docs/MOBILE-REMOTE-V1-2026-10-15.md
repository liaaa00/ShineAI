# 手机协同第一版交付记录 · 2026-10-15

后续已完成服务器部署和公网链路验收，详见 [公网部署记录](REMOTE-DEPLOYMENT-2026-10-15.md)。下文保留本地第一版交付时的范围。

## 已实现

手机浏览器访问自建服务器，登录、绑定电脑、查看明确共享的会话、发消息、读取回复、停止任务。电脑主动建立 WebSocket 出站连接，模型调用与项目操作在电脑执行；无需将电脑端口暴露到公网。

服务端在 `remote/server`，手机网页在 `remote/web`，电脑适配器在 `src/main/extensions/remote-bridge.cjs`，协议在 `src/shared/remote`。桌面右下角提供“手机协同”入口，默认关闭且不共享任何会话。

这套功能需要部署服务器后才能从外部手机使用。本地测试通过不代表公网部署完成。它也不是将完整桌面应用改造成服务器执行的 Web IDE。

- `npm run smoke:remote`：11 项端到端检查通过，实际运行 Electron、手机尺寸网页、本地服务器和 Claude CLI。模型由本地模拟服务提供，不使用用户密钥或付费模型。
- 端到端检查覆盖默认关闭、登录与绑定、会话授权、拒绝未共享会话、消息及回复同步、手机无桌面权限、任务完成前停止、断开、重连草稿、重启不重放、设备撤销。

- 独立服务器锁定依赖安装通过，`npm audit` 报告 0 个已知漏洞；这不代表整个桌面依赖快照完成无漏洞审计。

复测曾出现 CLI 启动等待和跨窗口操作后测试对话框不可见。专项脚本改为使用各自独立的模拟工作目录，并在需要时重新打开对话框；随后复测通过。停止测试直接观察模型请求正在执行，避免等回复完成后才点击停止。失败时会输出专项诊断，便于后续排查；这不代表对所有 Claude CLI 启动异常都已完成诊断。

本地报告和截图：`artifacts/remote-e2e-report.json`、`artifacts/remote-mobile.png`，均不进入版本库。

## 当前交付边界

- 单账号、单实例，最多绑定 20 台电脑；尚无独立用户注册与多租户隔离。
- 展示最近 30 条文字，每条末尾最多 4000 字符。未实现文件传输、完整历史翻页、手机审批和后台推送。
- 电脑必须开机并运行 ShineAI；手机权限沿用已共享会话的桌面配置，额外审批需要回电脑处理。
- 没有端到端加密，服务器运行环境需要受信任；公网必须使用 HTTPS。
- 本轮没有重新打包安装器，也没有替换日常运行的旧安装版。
- 公网域名、HTTPS 代理、真实手机网络与系统后台行为需部署后另行验收。

部署、登录账号管理及使用说明见 [remote/README.md](../remote/README.md)。
