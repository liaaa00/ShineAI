# 优化版 2

本轮围绕公开技能安装、MCP 配置和模型连接测试修复真实问题。官方公开技能和 MCP 市场继续保留，官方云账号、订阅及同步服务不恢复。

## 修复内容

- 技能正文下载失败、返回网页或空内容时明确失败；移除创建空技能并显示成功的降级逻辑。
- 仓库安装保留所在目录的脚本和资源，检查 Git 内容哈希、路径、大小及完整文件树，支持默认分支 HEAD 和小写 skill.md。同一技能并发安装被阻止。
- 下载瞬断、限流或服务端临时错误可以有限重试；文件和总体下载都有超时。安装进度按任务关联，失败保留此前安装。重复安装沿用原技能 ID 和启用状态。
- 文档中的使用或搜索示例不作为安装命令执行；显式安装提示仍支持，拒绝未替换占位符等无效命令。
- MCP 保存补齐数据库必需默认值，拒绝缺命令/服务地址的配置；数据库异常不再被吞掉，保存结果必须能读回。修改或启用不存在的 MCP 明确失败。
- MCP 市场新增配置默认关闭，必填环境变量和连接方式先验证；再次添加保留已有环境变量等自定义设置。
- MCP 连接测试验证 initialize 和 tools/list 的结构，不把任意 JSON 当成功；提供超时并清理测试进程。
- Claude、OpenAI Chat/Responses 和 Gemini 连接测试检查协议正文，HTTP 200 错误、网页、空响应均失败；界面超时后的迟到结果不覆盖超时状态。Codex 流式正文验证保持有效。
- 版本标识、可靠性回归脚本、带备份和回滚的安装目录更新脚本便于继续开发和排查。
