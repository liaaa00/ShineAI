# ShineAI 桌面切换

当前产品名、窗口、安装器、可执行文件、任务栏标识、托盘和桌面入口统一为
ShineAI。应用使用自己的日出图标，源文件为 `resources/shineai-mark.svg`，
`python scripts/generate-brand-assets.py` 可重新生成 Windows 和托盘资源。
这次切换不修改壁纸、透明度、字体效果或用户的会话正文。

已有独立开发版不能只替换 renderer：桥接名称、协议、内置 MCP 文件夹、
主进程环境变量和快捷方式必须一并更换。完整安装包包含当前工程的应用资源。

`scripts/migrate-independent-profile.py` 是手动执行的离线迁移工具，要求传入
旧独立开发版安装目录、旧 profile、新 profile 和全新备份目录。它拒绝官方版、
运行中的旧版、已存在的目标和链接路径；不会启动时自动读取其他应用的数据。
当前工具适用于已经设置自定义数据目录的独立开发版。默认目录用户需要另行
迁移路径相关的加密记录，工具会明确拒绝，避免生成无法解密的新 profile。

本机数据保留在用户设置的 `E:\AI`，新界面配置位于
`%APPDATA%\ShineAI\Desktop`。迁移先对真实数据库创建 SQLite 一致性备份，
复制原 profile 的偏好、壁纸和 Chromium 加密状态，校验文件内容，再发布新
profile。已有数据目录、密钥密文和用户内容不改写；缓存与历史日志不复制。
用户修改的项目路径和历史消息中出现的旧名称属于用户内容，不做批量替换。

`scripts/migrate-brand-catalog.py` 处理数据库中确切的旧内置 MCP 标识、默认
显示名和保留会话中的生成工具命名空间。它先创建新的数据库备份，在事务中
更新已知结构化引用；新旧内置条目冲突时拒绝合并，不接管同名自定义 MCP。
密码、环境变量、用户提示词和会话正文保持原值。它也不会启用已移除的云服务。

外部市场真实地址、旧云服务拦截域名、既有密文格式参数、原始许可和历史归档
仍保留必要的原始标识。它们不是新程序的产品名称，不能通过字符串替换更改。

Windows 安装器需要 `rcedit` 2.0.0，将二进制放到
`.runtime/packaging/rcedit-x64.exe`。来源：
<https://github.com/electron/rcedit/releases/download/v2.0.0/rcedit-x64.exe>。
SHA-256 固定在 `scripts/packaging/rcedit.sha256`。打包阶段校验工具哈希后写入
ShineAI 文件属性和图标；应用运行时不下载或执行此构建工具。

## 本机验收（2026-10-18）

新安装位于 `E:\AI\ShineAI`，桌面及开始菜单入口为 **ShineAI**。
旧独立开发版入口已备份后移除，官方独立安装保持原状。旧开发版目录和 profile
作为回退副本保留，不代表当前运行的程序仍使用旧产品标识。

实际安装的 1,734 个构建输出逐个通过 SHA-256 校验，EXE 与安装暂存版本一致，
Windows 文件属性、图标及托盘资源已验证。安装版品牌检查 7 项、本地端到端
检查 7 项、通知管理与跳转检查 5 项通过。通知测试替换了原生通知展示，验证
真实窗口恢复、preload 事件与会话导航；没有自动点击 Windows 系统通知。

迁移后实际启动读取到原有 6 个会话，供应商密钥、会话正文和壁纸配置与备份
一致。程序启动时会重新生成恢复上下文中的产品标题，并将内部 `CODEX_HOME`
切到新 profile 下相同的相对目录；用户正文、项目位置和自定义提示词未改写。
字体与透明效果沿用撤销字体自适应修改后的版本。

工程单元测试 68 项通过；完整检查中的本地 IPC 时延检查曾在大量安装文件写入时
超时，单独重跑通过（最大 106ms），编辑器检查也已单独通过。公共技能市场浏览、
安装及持久化测试通过。以上不包含真实付费模型调用或第三方账号服务验收。
