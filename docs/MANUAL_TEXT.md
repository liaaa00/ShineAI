# 手动文字效果

入口：设置 → 全部设置 → 外观 → 背景与玻璃效果 → **手动调整文字**。

默认关闭。旧配置加载时也保持关闭，不会改变原来的字体、字号、字重、文字颜色、
壁纸、透明度或模糊效果。开启壁纸后，可按需要勾选这个选项。

- **文字颜色**：默认跟随主题；选择“自定义”后使用颜色选择器调整普通主题文字。
- **描边宽度**：0～1 CSS px，步长 0.1。建议从很细的描边开始，0 关闭描边。
- **描边强度**：0～100%，与宽度分别调节；0 也关闭描边。
- **描边颜色**：手动选择，浅色主题初始为白色、暗色主题初始为黑色。
- **恢复默认文字**：仅重置当前明暗主题的文字设置，壁纸参数和另一主题不受影响。

文字设置在明暗主题下分别保存到本机。关闭“手动调整文字”可保留调节值并恢复
主题原样；关闭壁纸时文字覆盖也会停用。没有后台取色或逐帧自动变色。

细描边使用零模糊的文字阴影绘制，不增加文字底板，不强制加粗。普通主题文字
通过主题变量调整；状态色、链接强调色和语法颜色保留。Monaco、终端与代码块
不应用描边，代码区域保留主题变量。文字设置自身保留主题颜色，避免改色后无法
找到恢复按钮。写死颜色的第三方内容不保证跟随普通文字颜色设置。

任意视频都可能包含与文字同色的区域。手动文字效果方便取舍，不能保证完全
透明、画面不变的同时，每一帧的所有小字都达到同样的可读性。

验证命令：

```powershell
npm run check
npm run smoke:appearance
npm run smoke:manual-text
node scripts/manual-text-smoke.mjs --executable=E:/AI/ShineAI/ShineAI.exe
```

手动文字检查覆盖默认样式、字体字重、颜色与代码隔离、全透背景、零强度关闭、
关闭壁纸回退、明暗独立保存、重启持久化与仅恢复文字。使用隔离 profile 和生成
的测试壁纸，不使用真实模型凭证。实际结果保存在 `artifacts/manual-text/`。
