## 移除范围与未验收能力

官方账号登录、购买及续费、内置付费模型、组织协作、官方云会议、中继、在线发布、遥测和官方更新已移除。少量旧接口保留兼容返回值，不能执行原来的云端业务。详见 `云服务移除说明.md`。

Claude、Gemini、Copilot、其他 API 服务商、SSH、外部 MCP、语音硬件、机器人、工作流和多人任务未逐项做完整业务测试。相关原始模块及资源已保留，不能仅凭资源存在就认定所有组合都可用。

公开技能和 MCP 市场的浏览、刷新、下载与本地安装已恢复，不要求官方会员。官方社区发布接口仍移除。第三方技能 URL、独立服务商 OAuth 和系统协议唤起未完整实测；官方登录回调服务已删除，不能复用于第三方 OAuth。自备 API 或已有 Codex 配置的对话不依赖该回调。

市场恢复测试中 GitHub 的 raw 下载地址无法直连，默认 82 项来自随应用保留的目录回退。按钮安装使用实际带完整模板的市场条目；下载正文使用隔离的 localhost 测试源验证，不代表 GitHub 远程下载成功。公开 MCP 服务可连接，但本次小页数据只有远程类型，发布版映射没有显示条目；MCP 检查验收的是内置/自定义目录与配置保存，没有验收远程 MCP 运行。

## 工程边界

这是对官方发布客户端的独立重建，保留已编译的界面和业务模块，新增可读启动、配置、安全和兼容扩展。不是完整恢复作者的原始 TypeScript/React 源码，也没有服务端源码。后续应优先在 `src/main/extensions` 等可读目录开发，按指南逐步替换发布模块。
