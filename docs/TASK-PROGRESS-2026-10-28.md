# 会话运行进度

保留现有聊天布局与透明壁纸，仅在输入区上方增加透明的运行状态区。

## 用户可见行为

- 运行时显示旋转指示、中文动作和已用时，例如“正在读取文件”“正在生成回复”。
- 等待权限、计划确认或用户回答时停止动画，明确显示等待原因。
- 回复结束显示“本轮回复已结束”。工具失败、结果缺失分别显示失败或未确认。
- 回复结束但真实后台命令仍运行时，保持动画并显示后台任务数量；后台退出后再更新。
- “查看执行进度”可展开本轮中文操作名称与结果；命令、路径及原始日志保留原文。
- 计划面板“全部完成”更名为“计划步骤已完成”，不改变计划管理和完成比例逻辑。
- 没有保存语言偏好的用户默认启用现有的“始终中文回复”设置；用户明确关闭的选择继续保留。既有英文历史不自动翻译。
- 顶部已知固定运行提示翻译为中文，不翻译任意模型回答、错误或命令输出。

## 状态与证据

以会话生命周期、当前轮用户之后的消息、工具调用 ID 和后台任务记录为依据。成功操作数仅统计明确返回的工具结果或退出码 0；计划打勾、经过时间和回复文字均不能证明任务成功。不提供虚构百分比，也不假设所有任务必经固定阶段。

已用时表示本轮经过的时间，不表示完成比例。长时间未收到事件会提示仍在等待返回。后台任务在同一会话内持续跟踪，即使主回复已经结束。

实现位于 `src/renderer/assets/dev-task-progress.mjs` 和对应 CSS；集成转换位于 `scripts/patch-task-progress.mjs`，可重复执行。安装更新脚本仅修改五个相关文件，先准备全部转换、备份哈希，再写入，异常自动恢复。

- `npm run smoke:task-progress`：隔离 Electron 用户目录、回环 HTTP 固定响应、真实后台 Bash 命令，验证运行动画、计时、请求中的中文策略、回复结束后后台继续、真实退出后结束显示及窄窗口布局。
- `node scripts/task-progress-smoke.mjs --executable=E:/AI/ShineAI/ShineAI.exe`：同样流程验证安装文件，保留实际用户数据与运行任务。
