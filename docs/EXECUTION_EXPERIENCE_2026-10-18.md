# 执行记录与任务交付优化

2026-10-19 更新：按用户反馈，聊天输入区不再挂载“本轮记录”和请求摘要面板。
原生请求诊断的内存记录及消息右键菜单中的回滚入口保留。以下面板描述为初版记录，
当前常驻界面以此更新为准；桌面脚本已改为验证面板缺席和原消息菜单入口。

保留现有主题、默认字体和全透壁纸。本次没有修改外观配置，也没有恢复厂商云服务。

## 已实现

- 目录 Skill 的开关由数据库状态控制，搜索、目录查找、斜杠展开和 invoke_skill 共用判断。
  兼容旧导入 ID；同步目录时不会因“按命令查询只返回启用项”而重新启用停用的技能。
- 创建、恢复、派生会话、适配器参数及权限热更新保留 manual / balanced / full_auto。
  更多菜单提供逐次确认、平衡、完全授权，并显示实际选中状态。新会话默认仍为完全授权。
- Claude 的 PreToolUse 权限检查覆盖 SDK 预先允许的工具，避免 allowedTools 跳过手动确认。
  问答与计划审批继续使用原交互通道，已派发子会话的权限不追溯修改。
- Codex 原生 imageView / image_view 事件转为标准工具记录。处理重复事件、缺失开始事件、
  失败和取消；按工具调用 ID 配对，不把截图当成模型已查看图片。
- 执行组使用读取文件、读取图片、查看图片、截图、加载技能、测试命令等名称；保留原工具
  输入和输出，失败、尚未完成独立显示。
- 输入框上方新增可折叠的“本轮记录”：已记录的改动文件、差异卡片、HTML 预览、测试命令
  及结果、图片与技能记录。文件可打开到侧栏；没有测试证据时不会显示“测试通过”。
- “审阅 / 撤销本轮”进入原有预览，继续复用独立 shadow Git 快照，不重置用户仓库 HEAD。
  发送前等待快照结束；预览和撤销之间比对文件指纹，重做前也比对。恢复命令失败会保留
  对话；缺快照不静默把“撤销文件”变成“只回滚对话”。有未保存编辑时先要求保存/关闭。
- “查看请求摘要”只读显示本次进程中最近一次主会话请求，原生 API 在网络发送处记录
  协议、模型、思考参数、工具数量和 HTTP 状态。使用白名单，不记录密钥、请求头、地址、
  提示词、工具定义或附件。最多保存 100 个会话，退出即清除。

## 范围与限制

- 请求摘要目前能观察原生 OpenAI API 适配器的 Chat Completions / Responses 正文；
  Claude CLI、Codex CLI 等独立进程显示适配器配置及“尚未观察到网络正文”。不能用配置
  摘要或 HTTP 200 证明中转服务实际执行了思考强度。
- 数量来自工具事件。命令识别覆盖 npm/pnpm/yarn test/check/smoke、pytest、jest、vitest、
  Playwright、node --test、cargo/go test。自定义测试脚本仍可在原执行记录查看，未自动分类。
- 文件列表取自 fileChange 事件和成功写入工具记录，不宣称覆盖所有 shell 或第三方 MCP
  的文件副作用。测试命令成功只代表该命令成功，不代表整个应用功能全部通过。
- 技能候选、搜索和加载不是任务执行完成。Skills 指令加载后是否采纳，由模型实际行为决定。
- 撤销依赖原有快照覆盖范围和 Git 排除规则。二进制、大型资源、忽略文件等仍受这些规则
  约束。提交前会展示原有预览；快照失败时允许任务继续，但文件恢复不可用。并行外部进程
  仍可能在检查之后再次改文件，不能把预览指纹当成跨进程文件锁。

## 验证入口

- `npm run check`：完整单元、构建一致性及现有桌面回归。
- `node scripts/execution-experience-smoke.mjs`：隔离 profile 的实际 IPC、原生 API 到本地
  HTTP 服务、菜单选择、证据面板与文件侧栏、撤销预览和重启保留。面板工具消息是明确
  的固定样例，不等同于模型真实执行成功。
- `node scripts/permission-sdk-smoke.mjs`：实际打包 SDK/CLI 对本地模型样例执行 Write，
  验证 PreToolUse 在 allowedTools 预批准时仍可拒绝，完全授权时能写入临时文件。
- 单元测试直接加载现有 RollbackService，在临时目录实际创建快照和恢复，验证任务前
  未提交内容保留、预览后新改动被拦截、重做冲突被拦截。

恢复构建使用 `scripts/patch-execution-experience.mjs`，由 `apply-dev-transforms.mjs`
调用；新增业务逻辑保存在可读扩展与 renderer 模块中。
